# 文件地图

项目库放提案、记录、分析脚本与产物;论文正文在论文仓 `<论文仓路径>`,训练与评估代码在代码仓 `<代码仓路径>`。

## 目录怎么分

目录按来源分。硬规矩只有两条(有人类参与者时加第三条:身份数据不进项目库):`inputs/` 里的原始材料不改;`derived/` 里的东西由 `scripts/` 生成,手改无效。仓库自己算得出来的事实(文件数、某路径在不在)不手写,下面的数量块由 `scripts/repo_check.py --fix` 生成。

## 目录

| 目录 | 放什么 |
|---|---|
| `inputs/` | 原始材料:实验结果、语料、论文 PDF(有人类参与者时,身份数据不放这里) |
| `derived/` | 脚本产物:转好的论文 markdown、分析结果、仪表盘读的 `repo_state.md` |
| `records/` | 决定表、会话日志、检索协议、发现、计划;导师意见逐字放 `records/supervisor/` |
| `tracking/` | 任务卡、看板、文件地图、写作流程、风险 |
| `work/` | 提案与草稿 |
| `archive/` | 移出的旧状态、冻结的旧文件 |
| `scripts/` | 手写源码与测试 |
